# Cinova

A movie-focused frontend web application built to practice modern frontend development, responsive design, JavaScript functionality, and API integration.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Fetch API
* Vercel

## Features

* Movie-focused user interface
* Responsive layout
* Dynamic content rendering
* API-based data fetching
* Interactive frontend elements
* Clean and user-friendly interface

## Project Goals

The main goal of Cinova was to build a more complete frontend project while applying the JavaScript and web development concepts I learned through smaller projects.

I focused on:

* Building a structured and responsive frontend
* Working with API data
* Fetching and displaying dynamic content
* Creating interactive user interfaces
* Improving overall frontend code organization
* Deploying a project to a live hosting platform

## What I Learned

* How to fetch and work with data from an API
* How to render dynamic content on a webpage
* How to structure a larger frontend project
* How to build responsive layouts
* How to combine HTML, CSS, and JavaScript into a complete application
* How to deploy a frontend project using Vercel
